# Infinite Web Solutions - Official Website

![Infinite Web Solutions](assets/images/hero-tech.png)

Official single-page agency website for **Infinite Web Solutions** — bridging the gap between high-end visual identity and secure, scalable web architecture.

---

## ⚡ Tech Stack & Features

- **Theme**: Dark mode (`#07090E`), high-contrast, modern slate aesthetic.
- **Accents**: Tech-forward electric blue (`#3B82F6`) to vibrant purple (`#8B5CF6`) gradients.
- **Typography**: `Montserrat` (Headings) & `Inter` (Body Copy).
- **Styling**: Tailwind CSS + Custom CSS (`style.css`).
- **Interactivity**: Sticky header, smooth scroll-spy, infinite tech stack marquee, 4 pillars service cards, case study hover reveals, project preview lightbox modal, and interactive contact form.
- **Vercel Ready**: Preconfigured with `vercel.json` and `package.json` for one-click deployment.

---

## 🚀 One-Click Vercel Deployment

Deploying this website on Vercel is seamless:

1. Import your GitHub repository (`https://github.com/chandukanyal/Infinite-Web-Solutions.git`) into [Vercel](https://vercel.com).
2. Leave the Framework Preset as **Other** or **Static Storefront**.
3. Click **Deploy**. Vercel will automatically build and publish your site!

### Local Development Preview

You can run the project locally using Python's built-in HTTP server or `npx serve`:

```bash
# Using Python
python -m http.server 8000

# Or using Node / serve
npx serve .
```
Then visit `http://localhost:8000` in your web browser.
